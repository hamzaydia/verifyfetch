VerifyFetch Vite Example

v1.0.0 features: Streaming, Multi-CDN, Service Worker, Resumable Downloads

1. Basic Verified Fetch

Uses verifyFetch() - buffers response (convenient, O(n) memory)

2. Streaming Verification

Uses verifyFetchStream() - constant ~2MB memory

Note: Basic verifyFetch() buffers the response (same as native fetch). Use verifyFetchStream() for large files.

Key Features

Feature API Use Case
Streaming verifyFetchStream() Large files (AI models, WASM)
Multi-CDN verifyFetchFromSources() Failover if CDN compromised
Service Worker createVerifyWorker() Zero-code verification
Chunked Verification npx verifyfetch sign --chunked Fail-fast on corruption

Code Examples

Basic Fetch

import { verifyFetch } from 'verifyfetch'; const response = await verifyFetch('/model.bin', { sri: 'sha256-...' }); const data = await response.arrayBuffer();

Streaming (Constant Memory)

import { verifyFetchStream } from 'verifyfetch'; const { stream, verified } = await verifyFetchStream('/model.bin', { sri: 'sha256-...' }); for await (const chunk of stream) { await uploadToGPU(chunk); // Process immediately } await verified; // Throws if hash doesn't match
