CDN Asset Verification

Fetch files from CDN and verify their integrity before use.

Code Example

import { verifyFetch } from 'verifyfetch'; // Fetch and verify in one step const response = await verifyFetch( 'https://cdn.example.com/asset.js', { sri: 'sha256-...' } ); // Safe to use - integrity verified! const data = await response.text();
